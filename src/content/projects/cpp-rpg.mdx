<TabPanel id="overview">

The player sails from enemy to enemy toward Ithaca, earning gold, visiting shops, buying weapons and potions, and solving riddles. The design separates **data from logic**:

- `entity.txt` lists every hero and enemy (HP, stamina, defense, elemental weakness, gold, starting items).
- `items.txt` and `riddles.txt` hold the shop inventory and puzzles.
- `Entity`, `Map` and `Game` classes load the files, run the game loop and write results to `gameresults.txt`.

It was my largest program at the time (the main game file is about 1,360 lines), and it's where I learned to structure code into classes with clear responsibilities.
