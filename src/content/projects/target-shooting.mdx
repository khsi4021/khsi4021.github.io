<TabPanel id="overview">

I wrote all of the code for this team project; a teammate wrote the report. The state is [x, y, v, θ]. Drag is quadratic (C<sub>D</sub>/m = 0.002 m⁻¹) and two point fields add inverse-square accelerations, one repelling and one attracting. `ode45` integrates each shot, with **event functions** that stop it when it reaches the target's x, when the horizontal velocity reverses, or when it hits the ground.

<Figure src={traj} alt="Trajectories from the origin bending around a repelling field toward the target at (800, 800) m; the drag-free guess fails, the bisection solution hits." source="re-run of projects/target-shooting-sim (my code, unchanged)">
The drag-free angle (45.10°, from `fzero` on the vacuum trajectory) is the starting bracket, and flown through the full model it misses. Bisection on the **signed** miss distance converges to 46.149°.
</Figure>

</TabPanel>

<TabPanel id="technical">

<Equation tex={String.raw`\dot v = -\frac{C_D}{m}v^2 - g\sin\theta + \sum_i \frac{\alpha_i}{d_i^3}\,(\Delta x_i\cos\theta + \Delta y_i\sin\theta), \qquad \dot\theta = -\frac{g\cos\theta}{v} + \frac{1}{v}\sum_i \frac{\alpha_i}{d_i^3}(-\Delta x_i\sin\theta + \Delta y_i\cos\theta)`} />

The miss distance is signed by whether the shot passes above or below the target, which turns "hit the target" into a root-finding problem. The bracketing loop widens the interval until the sign changes, and the bisection keeps the best root seen so far, which makes it robust when the field makes the miss-distance function non-monotone.

</TabPanel>

<TabPanel id="results">

From the run used for this page: 72 iterations, a final miss of 2.8 × 10⁻⁵ m, and 8–17 s wall time on a laptop, since each iteration is a full ODE solve.

</TabPanel>
