# Design explorations

Three quick static mockups. Open them straight in a browser; no build step is needed. Each one loads Google Fonts for convenience. The real site self-hosts its fonts.

| File | Direction | Feel |
|---|---|---|
| `A-blueprint.html` | Technical drawing | Blue grid paper, line art, mono labels, a drawing title block. Strong personality, but heavy for long reading. |
| `B-research-journal.html` | Editorial research journal | Cream paper, serif type, abstracts, numbered figures and equations. Best for close reading by admissions committees, quieter for recruiters. |
| `C-aerospace-modern.html` | **Aerospace modern (built)** | Dark-first, high contrast, bow-shock and streamline motif, data read-outs, restrained motion. Follows the system's light/dark preference. |

The site is built in C, as the brief specifies. C borrows B's numbered figures and equations on project pages, so it reads well for both audiences.
